# Customer Web — Introduction

Welcome! This section explains how to get the Customer Web (the Next.js application) up and running on your computer. The steps are written for people who are not deeply technical — follow them one at a time and you'll be fine.

The project in this repository is built with Next.js and uses the same UI components you see in the documentation site (in `src/components`). You'll find step-by-step installation and run instructions in the Installation page.

What you'll learn here:

- What tools you need (Node.js and Visual Studio Code)
- How to install them on Windows
- How to install this project's dependencies and run it locally
- Basic troubleshooting if something doesn't work

When you're done, you'll be able to open the project locally, edit files in Visual Studio Code, and view the site at `http://localhost:3000`.

Next: go to the Installation page for clear, non-technical setup steps.
