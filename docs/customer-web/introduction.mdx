# Customer Web

Customer Web is the storefront where shoppers browse products, sign in, and place orders. It is a separate project from the Admin Panel that supplies its data.

1. [Check the prerequisites](/customer-web/prerequisites) and [install Customer Web](/customer-web/installation).
2. [Customize your branding](/customer-web/theme) and [add plugins](/customer-web/plugins) as needed.
3. [Publish the storefront](/customer-web/deployment) using the steps for your hosting.
