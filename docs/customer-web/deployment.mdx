# Deploying Customer Web

- **Shared hosting or cPanel:** Use [static export](#static-export).
- **Linux VPS or aaPanel with Node.js:** Use [server deployment (SSR)](#server-deployment-ssr).
- **Both methods:** The build must be able to reach your Admin Panel.

## Static export

1. Create `.env.local` next to `package.json` in your Customer Web folder.
2. Add these settings and replace the example addresses.

   ```env
   NEXT_PUBLIC_SSR=false
   NEXT_PUBLIC_ADMIN_PANEL_URL=https://admin.example.com
   NEXT_PUBLIC_SITE_URL=https://shop.example.com
   ```

   - **Admin Panel URL:** Use its base address, without `/api`.
   - **Site URL:** Use your public storefront address. It goes into the sitemap and search metadata.
   - Rebuild whenever you change either address.

### Automatic upload with FTP

1. Add your hosting provider's FTP details to the same `.env.local` file.

   ```env
   FTP_HOST=ftp.example.com
   FTP_USER=your-ftp-user
   FTP_PASSWORD="replace-with-your-ftp-password"
   ```

2. Check the FTP settings.

   - **Destination:** Use an FTP account whose root (`/`) is your website folder, such as `public_html`.
   - **Port:** Add `FTP_PORT` if your host uses a port other than 21.
   - **Explicit FTPS:** Add `FTP_SECURE=true` if your host requires it.
   - **Credentials:** Keep `.env.local` on the upload computer and out of Git. The script uses it to sign in.

3. Check upload access. This command uploads, reads, and removes a small test file.

   ```bash
   npm run test:ftp
   ```

4. Confirm that `NEXT_PUBLIC_SSR=false` in `.env.local`. Clear any conflicting `NEXT_PUBLIC_SSR=true` in your terminal or `.env.production.local`.

   > **Use FTP deploy for static export only.** In SSR mode the uploader sends project files, including environment files. Follow the server deployment steps for SSR.

5. Publish. This installs dependencies, builds the site, and uploads only the contents of `out/` in static mode.

   ```bash
   npm run deploy
   ```

### Manual upload

1. Run `npm run build`.
2. Upload the **contents** of `out/` to your website folder. Use your host's file manager or FTP client and keep the folder structure.
3. Set up the URL rules for your host.
   - **Apache or cPanel:** Include the generated `.htaccess` from `out/`.
   - **Nginx:** Ask your host to set up equivalent URL rules.

**For either upload method:** FTP replaces matching files and leaves old ones on the server. Remove stale files for any plugin or page you removed.

## Server deployment (SSR)

- **Server tools:** Linux, Git, Node.js 22, PM2, Bash, `tar`, and `flock`.
- **Server account:** Use the same account that owns the Customer Web checkout and runs PM2.

1. In the **server's** Customer Web folder, create the settings file.

   ```bash
   cp .env.ssr.example .env.production.local
   ```

2. Set your Admin Panel URL and public site URL in `.env.production.local`. Keep `NEXT_PUBLIC_SSR=true`.
3. Commit the release to your deployment branch. The server builds from Git. Changes and plugins that exist only on your computer won't be included.
4. Deploy on the server.

   ```bash
   npm run deploy:ssr
   ```

   - The script fetches `main` by default. Set `DEPLOY_BRANCH` to use another branch.
   - PM2 switches to the new release after the build succeeds.

5. Connect and verify your domain.
   - In aaPanel or Nginx, set the reverse proxy to `http://127.0.0.1:3003`.
   - Enable HTTPS.
   - Run `pm2 status` and check that `hyperlocal-web` is running.

**Managed Node.js host**

- Add the two URLs and `NEXT_PUBLIC_SSR=true` in your hosting dashboard.
- If the host asks for commands, use `npm run build:ssr` to build and `npm start` to start.

## After publishing

- Open the live site over HTTPS. Check the home page, a product page, sign-in, and cart.
- Check that `/robots.txt` and `/sitemap.xml` reference your public domain.

**If something fails**

- **Build:** Check both URLs and confirm the build machine can reach the Admin Panel.
- **FTP:** Run `npm run test:ftp` and share the reported step with your host.
- **SSR:** Check `pm2 logs hyperlocal-web --lines 50`.
