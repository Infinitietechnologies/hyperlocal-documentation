# Theming in Your Project

Use **Web Settings** for everyday branding changes. Edit theme files when you want to change the storefront's defaults or layout.

## Change branding in the Admin Panel

Go to **Settings → Web Settings**. Change the fields below, save, and refresh the storefront.

| What to change | Where to find it | What it affects |
| --- | --- | --- |
| Primary Color | Color Scheme | The main color on primary buttons, links, highlights, and focus outlines that use the theme. |
| Font Color | Color Scheme | Default text that uses the theme. Check that it stays readable in both light and dark modes. |
| Header, dark header, and footer logos | General | The logo in the light header, dark header, and footer respectively. |
| Site Favicon | General | The small icon in the browser tab. Your browser may take time to show the new icon. |

The saved **Primary Color** and **Font Color** apply to both modes and override the corresponding defaults in the theme files.

## Change defaults in your web project

Open these files in the Customer Web source folder.

| File and setting | What changes |
| --- | --- |
| `tailwind.config.ts` → `themes.light.colors` and `themes.dark.colors` | `background` is the page surface, `foreground` is default text, and `primary.DEFAULT` is the default accent. Edit each mode separately. If you change the accent, keep `primary.500` and the other shades in the same palette. |
| `tailwind.config.ts` → `theme.extend.fontSize` and `theme.extend.screens` | Font sizes change text using those size names. Screen widths change when responsive layouts switch, such as when `md:` styles start. |
| `src/config/fonts.ts` | The bundled default font, currently Lexend Deca. Changing it affects text using the default font. |
| `src/styles/globals.css` | Site-wide CSS rules, such as scrollbar styles. Use the relevant component's style for a change confined to one section. |

For example, to make the light theme's page background warm white, find `themes.light.colors.background` in `tailwind.config.ts` and change it to `#faf7f2`. Check that the text still contrasts with it. The dark theme has its own background setting.

### Theme configuration file

Open `tailwind.config.ts` beside `package.json` in your Customer Web folder.

import { heroui } from "@heroui/theme";

/** @type {import('tailwindcss').Config} */
const config: import("tailwindcss").Config = {
  content: [
    "./src/layouts/**/*.{js,ts,jsx,tsx,mdx}",
    "./src/pages/**/*.{js,ts,jsx,tsx,mdx}",
    "./src/components/**/*.{js,ts,jsx,tsx,mdx}",
    "./src/**/*.{js,ts,jsx,tsx,mdx}",
    "./node_modules/@heroui/theme/dist/**/*.{js,ts,jsx,tsx}",
  ],
  theme: {
    extend: {
      fontWeight: {
        thin: "50", // was 100
        extralight: "150", // was 200
        light: "250", // was 300
        normal: "350", // was 400
        medium: "450", // was 500
        semibold: "550", // was 600
        bold: "600", // was 700
        extrabold: "750", // was 800
        black: "850", // was 900
      },
      fontFamily: {
        sans: ["var(--font-storefront, var(--font-sans))"],
        mono: ["var(--font-storefront, var(--font-mono))"],
      },
      fontSize: {
        tiny: "0.4375rem", // 7px
        xxs: "0.625rem", // 10px
        xs: "0.75rem", // 12px
        small: "0.875rem", // 14px
        medium: "0.9375rem", // 15px
        large: "1.125rem", // 18px
      },
      width: {
        // Full-bleed sections use the page container's content width, which
        // excludes classic scrollbars unlike 100vw.
        page: "100cqw",
      },
      screens: {
        xxs: "320px",
        xs: "375px",
        sm: "431px",

  darkMode: "class",
  plugins: [

      },

        light: {
          colors: {
            background: "#ffffff",

          },
        },
        dark: {
          colors: {
