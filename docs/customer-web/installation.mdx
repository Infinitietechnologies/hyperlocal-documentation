# Install Customer Web

## Get the tools and source files

1. Install [Node.js 22](https://nodejs.org/en/download/archive/v22). The installer includes npm.
2. Extract your Customer Web download. Open the web folder containing `package.json` in your editor, such as Visual Studio Code.
3. Open a terminal in that folder and install the project dependencies.

```bash
npm install
```

On Windows, if PowerShell blocks `npm.ps1`, use Command Prompt in the same folder or type `npm.cmd install` in PowerShell.

## Configure your site

Create a file named `.env.local` next to `package.json`. If it already exists, update these lines in it. Replace the Admin Panel address with yours, without adding `/api`.

```env
NEXT_PUBLIC_ADMIN_PANEL_URL=https://admin.example.com
NEXT_PUBLIC_SITE_URL=http://localhost:3000
```

Your Admin Panel must be reachable. See [Customer Web prerequisites](/customer-web/prerequisites) for web sign-in, notifications, and maps. When publishing, change the site URL to your public domain and follow the [deployment guide](/customer-web/deployment) for the settings your host needs.

## Open the storefront

```bash
npm run dev
```

Open the address shown in the terminal, usually [http://localhost:3000](http://localhost:3000). If you change `.env.local`, stop the server with Ctrl+C and run the command again.

You can now [change the theme](/customer-web/theme) or [add optional plugins](/customer-web/plugins).
