# Mobile Apps Overview

Our mobile ecosystem consists of four Flutter-based applications, each serving a specific role in the platform:

## Customer App

The main shopping application for end users to:

- Browse and purchase products
- Track orders in real-time
- Manage their profile and addresses
- View order history
- Chat with sellers and support

## Delivery App

Helps delivery partners to:

- Accept and manage deliveries
- Navigate to pickup/delivery locations
- Update order status
- Track earnings
- Manage their schedule

## Technical Stack

All mobile applications are built using:

- **Flutter** - Google's UI toolkit for building natively compiled applications
- **Dart** - The programming language used with Flutter
- **Provider/Bloc** - For state management
- **REST APIs** - For backend communication
- **Firebase** - For notifications and real-time features
- **Google Maps** - For location services and navigation

## Getting Started

To begin developing any of these applications:

1. First, complete the [Flutter Setup](/mobile-apps/flutter-setup) guide
2. Choose the specific app you want to work on:
   - [Customer App](/mobile-apps/customer-app/introduction)
   - [Delivery App](/mobile-apps/delivery-app/introduction)

Each app has its own setup guide and configuration requirements.
