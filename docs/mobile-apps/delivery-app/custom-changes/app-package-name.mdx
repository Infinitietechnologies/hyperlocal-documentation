# App Package / Bundle Name

Follow these steps to rename the app identifiers for both Android and iOS.

---

## Quick rename (Android & iOS) via package

You can rename both Android and iOS identifiers in one step using the `change_app_package_name` package:

```bash
# From project root
# For both android and ios
dart run change_app_package_name:main com.yourcompany.partner


# For android specific
dart run change_app_package_name:main com.yourcompany.partner --android


# For ios specific
dart run change_app_package_name:main com.yourcompany.partner --ios
```

After running, verify:
- Android package path and ids are updated.
- iOS bundle identifier is updated.
- Rebuild both apps.

---

## Checklist

- Android `applicationId` and `namespace` updated to the new package.
- iOS Bundle Identifier updated in Xcode.
- Firebase app records (Android/iOS) match the new identifiers.
- Rebuilt both Android and iOS after the changes.
