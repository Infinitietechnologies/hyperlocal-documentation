# Prerequisites — Delivery App (Admin & Firebase)

Before running or deploying the Flutter Delivery App (Android/iOS), make sure the **Admin Panel** and **Firebase** are correctly set up.  
All required configuration — such as Firebase credentials — must be entered **inside the Admin Panel**.

---

## 1) Admin Panel Setup

- Make sure the Admin Panel is fully set up and accessible from a subdomain, for example:

- Obtain the **Admin URL** and **login credentials** from your technical team.
- You will manage all configuration (Firebase, etc.) from the Admin Panel directly.
- The Delivery App connects automatically to the Admin Panel API — no need to edit any local environment variables.

---

## 2) Firebase Configuration (Flutter Android & iOS)

To use authentication or push notifications, you must set up Firebase for both Android and iOS. There are two ways to do this:

### Method 1: Using FlutterFire CLI (Recommended)

Using the **FlutterFire CLI** is the fastest and most reliable way to configure Firebase. It handles the heavy lifting of generating the correct configuration files for all your target platforms automatically.

#### Step 1: Install Firebase CLI
The Firebase CLI provides a variety of tools for managing, viewing, and deploying to Firebase projects.
```bash
# Install globally using npm
npm install -g firebase-tools
```

#### Step 2: Log in to Firebase
This command opens a browser window where you can log in to your Google account associated with your Firebase projects.
```bash
firebase login
```
> [!NOTE]
> If you are on a remote machine or a server without a browser, use `firebase login --no-localhost`.

#### Step 3: Install FlutterFire CLI
The FlutterFire CLI is a useful tool that provides commands to help ease the installation process of FlutterFire.
```bash
# Activate the CLI globally
flutter pub global activate flutterfire_cli
```
> [!TIP]
> Ensure your system's PATH includes the Flutter bin directory so you can run `flutterfire` from anywhere. For MacOS/Linux, this is usually `~/.pub-cache/bin`.

#### Step 4: Configure the Project
This is the most critical step. Run this command from the **root of your Flutter project**. It is an interactive command that will guide you through the process.

```bash
flutterfire configure
```

**Interactive Prompts during configuration:**

1.  **Project Selection:** Select your Firebase project from the list.
2.  **Platform Selection:** Toggle **android** and **ios** using the Spacebar.
3.  **Question:** `✔ You have an existing firebase.json file and possibly already configured your project for Firebase. Would you prefer to reuse the values in your existing firebase.json file to configure your project?`
    - **Answer:** **no** (Type 'no' and Press Enter)
4.  **Question: File lib/firebase_options.dart already exists. Do you want to overwrite it?**
    - **Answer:** **Yes** (Press Enter)
    - *Rationale:* This ensures the file is updated with your specific project credentials.

**Example Success Output:**
```bash
✔ Firebase configuration file lib/firebase_options.dart generated successfully with the following Firebase apps:

Platform  Firebase App Id
android   1:123456789012:android:xxxxxxxxxxxxxxxx
ios       1:123456789012:ios:xxxxxxxxxxxxxxxx
```

### Common Steps (Required for both methods)

After completing either method above, you must initialize Firebase in your code and enable authentication providers.

#### 1. Initialize Firebase in Code
Update `lib/main.dart`:
```dart
import 'package:firebase_core/firebase_core.dart';
import 'firebase_options.dart';

void main() async {
  WidgetsFlutterBinding.ensureInitialized();
  await Firebase.initializeApp(
    options: DefaultFirebaseOptions.currentPlatform,
  );
  runApp(const MyApp());
}
```

#### 2. Enable Authentication Providers
In **Firebase Console → Authentication → Sign-in method**, enable: **Phone**, **Google**, **Email/Password**, and **Apple**.

## 3) Final Checklist

✅ Admin Panel is hosted and reachable on a subdomain.  
✅ Firebase (Android `google-services.json` + iOS `GoogleService-Info.plist`) is added and keys stored in Admin Panel.  
✅ FCM Server key / service account JSON is added in Admin Panel Notifications.

Once these are completed, you can run the Flutter Delivery App for Android and iOS.
