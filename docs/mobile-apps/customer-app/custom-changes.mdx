# Custom Changes Overview

This section covers all the custom changes you need to make to configure and brand your Flutter customer app. Follow each guide below to update app branding, URLs, Firebase, and map keys.

## Available Customizations

1. **[App Package / Bundle Name](./custom-changes/app-package-name)** - Set Android package and iOS bundle ID
1. **[App Logo](./custom-changes/app-logo)** - Update app icons for Android and iOS
2. **[App Name](./custom-changes/app-name)** - Change the app display name
3. **[App Base URL](./custom-changes/app-url)** - Configure API endpoints
4. **[Firebase Server Client ID](./custom-changes/firebase-client-id)** - Set up Firebase authentication
5. **[Android Maps API Key](./custom-changes/android-maps-key)** - Configure Google Maps for Android
6. **[iOS Maps API Key](./custom-changes/ios-maps-key)** - Configure Google Maps for iOS

## Quick Checklist

After making all changes, verify:

- ✅ App logo appears correctly on both platforms
- ✅ App name displays correctly in app launcher and settings
- ✅ API calls work with the configured base URL
- ✅ Firebase authentication functions properly
- ✅ Maps display correctly on both Android and iOS

## Next Steps

Once you've completed all custom changes, proceed to [Deployment](../deployment) to build and publish your app.
