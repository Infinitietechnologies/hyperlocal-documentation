# App Base URL

Configure the API base URL constants in `lib/config/constant.dart` and verify that every API call points to the correct environment.

---

## Configuration

**File:** `lib/config/constant.dart`

```dart
// lib/config/constant.dart
class AppConstant {
  // Production URL
  static const baseUrl = 'https://api.example.com/api/';
}
```

![Base URL constant](/images/custom-changes/base-url.png)

---

## Usage in API Calls

**Service example**

```dart
import 'package:http/http.dart' as http;
import 'config/constant.dart';

class ApiRoutes {
  static String loginApi = '${AppConstant.baseUrl}login';
  static String registerApi = '${AppConstant.baseUrl}register';
  static String verifyUserApi = '${AppConstant.baseUrl}verify-user';
  // Other APIs
}
```

---

## Verification

1. Test API calls in the app (e.g., login/register).
2. Confirm network requests hit the intended endpoint.
3. Check logs to confirm the URL being used.
4. Test all environments (dev, staging, production) if configured.
